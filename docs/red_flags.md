# Красные флаги (раздел 7.4 регламента)

Детектор в `app/services/red_flags.py` распознаёт две категории:

**Категория А (Угроза жизни, R-01 → 103/112 + P1):**
Боль в груди, нарушение дыхания, потеря сознания, инсульт, судороги, кровотечение, тяжелые травмы, аллергия (отек), угроза жизни детям, беременность, угроза себе.

**Категория Б (Острое состояние, R-11 → Регистратор P1):**
Острая боль, высокая температура (40+), резкое ухудшение, травма без угрозы.

При срабатывании флага диалог немедленно прерывается, пациенту говорится фраза про скорую, а в МИС создаётся заявка на эвакуацию.
