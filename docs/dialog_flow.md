# Сценарии диалога

Ассистент работает на базе детерминированного state machine.

**Реализованные сценарии:**
- **C-01 (Запись):** greeting → ask_name → ask_specialty → offer_slots → confirm → booked.
- **C-04 (Отмена):** поиск клиента → список записей → подтверждение → отмена (PATCH в МИС).
- **C-05 (Проверка):** поиск клиента → вывод активных записей.
- **C-14 (Красный флаг):** детектор (red_flags.py) прерывает любой сценарий, рекомендует 103/112, создаёт эскалацию P1.
- **C-15 (Жалоба):** перевод на старшего администратора (P2), создание эскалации в МИС.

Сценарии изолированы в `app/services/dialog/scenarios/`.
